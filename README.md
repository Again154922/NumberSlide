# NumberSlide / 数字华容道

一个使用纯 C# 核心逻辑实现的数字华容道，目前提供控制台版本，并计划复用同一套 Core 开发 Unity 版本。

目标是同时提供一个可玩的滑块解谜游戏，以及围绕状态表示、可解性判定和启发式搜索的 C# 学习项目。

## 当前功能

- 支持 3×3、4×4 和 5×5～10×10 棋盘。
- 随机生成合法且可解的初始局面。
- 方向键或 `W/A/S/D` 移动方块。
- `Z` 撤销上一步。
- `R` 重新生成棋盘。
- `Q` 或 `Esc` 退出。
- 完成局面后显示最终棋盘和通关提示。
- 控制台棋盘固定列宽显示，数字 `0` 显示为空格。

## 运行

需要 .NET 10 SDK。

```bash
dotnet build NumberSlide.sln
dotnet run --project src/NumberSlideConsole/NumberSlideConsole.csproj
```

控制台启动后，输入棋盘宽度 `3`～`10` 即可开始游戏。

## 项目结构

```text
NumberSlide/
├── NumberSlide.sln
├── src/
│   ├── NumberSlide.Core/
│   └── NumberSlideConsole/
└── docs/
```

- `NumberSlide.Core`：棋盘状态、编号生成、可解性判定、移动、撤销和完成判断。
- `NumberSlideConsole`：终端输入输出、清屏、棋盘布局和提示信息。

Core 不依赖控制台或 Unity API。后续 Unity 版本应通过 Core 公开的游戏对象调用逻辑，而不是复制规则。

## 核心规则

棋盘使用数字 `1..N²-1` 和唯一的空格 `0`。每次操作只移动与空格相邻的方块，把数字恢复到从左到右、从上到下的顺序，并将空格留在右下角。

棋盘不会生成不可解排列。随机生成时先构造完整排列，再通过逆序数奇偶性保证局面可解。

## 技术说明

方向键表示方块的移动方向，因此空格会向相反方向移动。例如按左键时，空格向右移动，空格右侧的方块滑入旧空格位置。

`NumberSlide.Core` 目前同时限制棋盘宽度为 `3..16`；控制台界面开放的范围是 `3..10`。
